# GhostAI Private Sync

Private, app-managed storage for encrypted GhostAI cross-device synchronization.

The app must encrypt conversation, memory, and research payloads before uploading them. Private repository visibility is an access control, not a replacement for encryption.

Never commit plaintext personal data, passwords, API tokens, or encryption keys. Keep authentication credentials and encryption keys in the app's secure device storage.

This repository is initialized with this generic README only. No user data or credentials are included.
